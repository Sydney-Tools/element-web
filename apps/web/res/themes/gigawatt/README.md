# Gigawatt theme

Our built-in theme: Element's dark theme plus `_gigawatt.pcss`. Selected
with `default_theme: "gigawatt"` in config.json and listed first in the
theme picker. Change colours here, not in config.json custom themes.

Feature components (agent runs, approval cards, flux meter) get their CSS
under `res/css/gigawatt/`, registered in `res/css/_components.pcss`; this
directory only decides how Gigawatt looks.
